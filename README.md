# Create a Tree Grid in Blazor Server application in 10 Minutes

This sample demonstrates the Syncfusion [Blazor TreeGrid](https://www.syncfusion.com/blazor-components/blazor-tree-grid) component in a Blazor Server application. The application displays hierarchical parent-child records in a tree-structured grid and shows how to organize and visualize related data efficiently. The sample also demonstrates expand and collapse functionality together with common data operations such as paging, sorting, and filtering. It serves as a quick-start reference for developers who want to implement hierarchical data presentation using the Syncfusion TreeGrid component in Blazor Server.

Watch the video now: https://www.syncfusion.com/tutorial-videos/blazor/tree-grid?title=create-a-tree-grid-in-blazor-server-application-in-10

Documentation: https://blazor.syncfusion.com/documentation/treegrid/getting-started

Online example: https://blazor.syncfusion.com/demos/tree-grid/default-functionalities

## Key Features

- Displays hierarchical data using the Syncfusion TreeGrid component.
- Demonstrates parent-child record binding in a tree-structured view.
- Supports row expansion and collapse for navigating hierarchical records.
- Configures TreeGrid columns to display structured business data.
- Demonstrates paging for managing larger data collections.
- Demonstrates sorting functionality for organizing displayed records.
- Demonstrates filtering functionality for quickly locating records.
- Uses a sample data source from the application's data layer.
- Provides a Blazor Server implementation suitable for learning TreeGrid fundamentals and project setup.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `TreeGridSample.sln`

3. Restore NuGet packages.
4. Ensure the startup project is:

   `TreeGridSample`

5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory containing `TreeGridSample.csproj`.
4. Restore packages and run the application:

```bash
dotnet restore
dotnet run
```
