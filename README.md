# Blazor TreeGrid Quick Start

A comprehensive guide to building a Blazor Server application with the [Blazor TreeGrid](https://www.syncfusion.com/blazor-components/blazor-tree-grid) component. Get up and running in 10 minutes with hierarchical data visualization, built-in features like sorting, filtering, and paging.

## Overview

This sample demonstrates how to integrate the Blazor TreeGrid component into a Blazor Server application. You'll learn how to:

- Display hierarchical parent-child data with expandable rows
- Configure columns with various data types
- Implement sorting, filtering, and paging
- Work with business objects and data binding

The TreeGrid is ideal for displaying hierarchical data structures such as task hierarchies, organizational charts, file systems, and project schedules.

## Features

- **Hierarchical Data Display**: Expand and collapse parent-child relationships
- **Built-in Sorting**: Sort data by any column in ascending or descending order
- **Advanced Filtering**: Filter data to quickly find relevant records
- **Smart Paging**: Navigate through large datasets with configurable page sizes
- **Responsive Design**: Works seamlessly across different screen sizes

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/SyncfusionExamples/Create-a-Tree-Grid-in-Blazor-Server-application-in-10-Minutes.git
cd Create-a-Tree-Grid-in-Blazor-Server-application-in-10-Minutes
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
